# openmls-wasm

The wasm-bindgen facade of [`openmls-core`](../openmls-core): Pīna'i's MLS engine as the web client loads it.
wasm-pack builds it into `../openmls-pkg/` — `./build.sh`, or `scripts/build-wasm.mjs` from the apps' scripts.
The engine, its rules and how to build it: [`../README.md`](../README.md).
